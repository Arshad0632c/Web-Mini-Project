# Netflix UI Clone 🎬

A responsive Netflix UI clone built with HTML5 and CSS3. Includes movie previews, TV show previews, and a clean dark theme interface.

## 🚀 Live Demo
Once GitHub Pages is enabled, the site will be accessible at:
- **GitHub Pages**: `https://<your-username>.github.io/<repo-name>/`

## 📁 Pages Included
- `index.html` - Homepage / Landing page with hero banner and CTA.
- `movies.html` - Movie preview showcase with video player grid.
- `tvshows.html` - TV shows preview showcase with video player grid.

## 🛠️ Built With
- HTML5 (Semantic Structure, Video embeds)
- CSS3 (Flexbox, Grid layout, responsive media queries, hover transitions)
- JavaScript
